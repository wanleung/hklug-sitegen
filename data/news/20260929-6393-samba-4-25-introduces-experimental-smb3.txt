Title: Samba 4.25 Introduces Experimental SMB3 Persistent Handles for Improved File Resilience
Content:
<p>The Samba project has released version 4.25 of its open-source file and print sharing suite, a significant update that introduces experimental support for a long-anticipated feature aimed at dramatically improving reliability in mixed Windows and Linux environments.</p>
<p>The headline addition is experimental support for SMB3 Persistent Handles. This feature, detailed in a release announcement reported by Phoronix, allows a client application that disconnects from a file server—due to a temporary network outage or a server reboot, for example—to reconnect and seamlessly resume work on open files without data loss or application crashes.</p>
<p>For system administrators managing critical workloads such as virtual machine disks or database files stored on SMB shares, this capability represents a major step toward the high-availability features long considered standard in Microsoft's proprietary Windows Server implementation of the SMB protocol. Persistent handles have been a native feature of Windows Server since 2012, providing a robust failover mechanism that enterprise environments have come to depend on.</p>
<p>"It closes a significant functionality gap," the release notes indicate. With this experimental implementation, Samba-based file servers can now offer similar resilience to Windows-based SMB shares, potentially altering cost and flexibility calculations for organizations running hybrid infrastructure. However, the Samba team is clear that the feature is not yet hardened for universal production use and advises administrators to conduct thorough testing in non-critical environments.</p>
<p>Beyond the new persistent handles, Samba 4.25 includes a suite of updates focused on security and performance. The release incorporates security hardening, improvements to authentication handling for both Kerberos and NTLM, and various performance optimizations. These updates continue the project's ongoing work to maintain a secure, high-performing, and compatible implementation of the SMB protocol.</p>
<p>The release positions Samba as an increasingly viable option for mission-critical file services, not just as a compatibility bridge but as a robust server platform in its own right. The experimental persistent handles feature is a clear signal of the project's ambition to match, and perhaps in time exceed, the reliability standards set by proprietary offerings.</p>
<p>For IT teams in Hong Kong and elsewhere managing fleets of Windows clients against a backbone of Linux infrastructure, Samba 4.25 offers a compelling reason to begin planning for more resilient file sharing architectures. As the feature matures through community testing and feedback, it could become a cornerstone for building truly fault-tolerant cross-platform file services.</p>
<hr>
<p>Samba 項目已發布其開源檔案及打印共享套件的 4.25 版本，這是一次重大更新，引入了針對一項市場期待已久功能的實驗性支持，旨在顯著提升 Windows 和 Linux 混合環境下的可靠性。</p>
<p>此次發布的核心新增功能是對 <strong>SMB3 持續手柄</strong> 的實驗性支持。這項功能在 Phoronix 報導的发布公告中有詳細說明，它允許因（例如）暫時性網絡中斷或伺服器重啟而斷開連接的客戶端應用程序，能夠重新連接並無縫恢復對已開啟檔案的工作，不會出現數據丟失或應用程序崩潰的情況。</p>
<p>對於管理儲存在 SMB 共享中的虛擬機磁盤或數據庫文件等關鍵工作負載的系統管理員而言，這項能力代表著朝著 Microsoft 專有 Windows Server SMB 協議實現中長期被視為標準的高可用性功能邁進了重要一步。持續手柄自 2012 年起一直是 Windows Server 的原生功能，提供了一套強大的故障轉移機制，企業環境已對此形成依賴。</p>
<p>「它填補了一個重要的功能缺口，」發布說明指出。借助這項實驗性實現，基於 Samba 的檔案伺服器現在可以提供與基於 Windows 的 SMB 共享類似的恢復能力，這可能改變運行混合架構組織的成本與靈活性計算。然而，Samba 團隊明確表示，該功能尚未完全成熟以適用於普遍的生產環境，並建議管理員在非關鍵環境中進行全面測試。</p>
<p>除了新的持續手柄功能，Samba 4.25 還包含一系列側重於安全性和性能的更新。此次發布整合了安全強化措施，改進了對 Kerberos 和 NTLM 的認證處理，並進行了多項性能優化。這些更新延續了該項目持續致力於維護一個安全、高性能且兼容的 SMB 協議實現的工作。</p>
<p>此次發布將 Samba 定位為一個日益可行的關鍵任務檔案服務選項，不僅僅是作為兼容性橋樑，更是作為一個本身就很強大的伺服器平台。實驗性的持續手柄功能明確顯示了該項目旨在匹配，甚至可能在未來超越，專有產品所設定的可靠性標準的雄心。</p>
<p>對於香港及其他地區管理大量 Windows 客戶端並以 Linux 基礎架構為骨幹的 IT 團隊而言，Samba 4.25 提供了一個令人信服的理由，開始規劃更具恢復能力的檔案共享架構。隨著該功能通過社區測試和反饋走向成熟，它可能成為構建真正容錯的跨平台檔案服務的基石。</p>
