Title: Linux Patches Posted to Enable NVMe Storage Across Apple's Entire M3 Chip Family
Content:
<p>A critical set of patches has been submitted to the Linux kernel mailing list to enable Non-Volatile Memory Express (NVMe) storage support for all variants of Apple's M3 system-on-a-chip (SoC). This development represents a foundational step toward making Apple's latest generation of Silicon hardware a practical platform for running Linux.</p>
<p>As reported by Phoronix, the new patch series targets the M3, M3 Pro, M3 Max, and M3 Ultra chips. While earlier Linux kernel releases laid the groundwork for M3 recognition, the system could not yet handle primary storage. Without functional NVMe drivers, a Linux installation on these machines remains at a basic hardware-identification stage, unable to boot into a usable operating system or access the main drive.</p>
<p>The enablement of NVMe is a gating requirement for moving the platform forward. Successful integration of these patches would allow the kernel to communicate with the flash storage controller on the M3 dies, a prerequisite for booting and running a filesystem. This milestone shifts the conversation from initial hardware discovery to the development of a bootable, functional Linux environment on Apple's newest computers.</p>
<p>However, a significant dependency has been noted. The patches are designed to work in conjunction with an updated Apple Secure Boot Manager firmware. This firmware update is typically delivered through macOS software updates. Consequently, users will need to ensure their machines have the required firmware revision before the kernel-level patches can function correctly, a common constraint within Apple's tightly integrated ecosystem.</p>
<p>The patches are currently in the review and testing phase, undergoing scrutiny from kernel maintainers and the broader developer community. Community validation on real M3 hardware is the crucial next step. Developers and enthusiasts with access to M3-based Macs will play a vital role in testing the patches, reporting bugs, and ensuring stability across the diverse range of M3 configurations.</p>
<p>This progress is part of the ongoing, incremental effort to bring full Linux support to Apple Silicon. While a polished, daily-driver experience on M3 remains a future goal, each upstream patch that enables a core component like storage moves the community closer. For developers and tinkerers aiming to build or experiment with Linux on the latest Apple hardware, the enablement of NVMe is the essential key that unlocks the door to further work.</p>
<hr>
<p>一套關鍵的補丁已提交至 Linux 核心郵件列表，旨在為 Apple 所有 M3 系統級晶片（SoC）變體啟用非揮發性記憶體高速介面（NVMe）儲存支援。此發展代表著讓 Apple 最新一代 Silicon 硬體成為可實際運行 Linux 平台的基礎性一步。</p>
<p>據 Phoronix 報導，新的補丁系列針對 M3、M3 Pro、M3 Max 及 M3 Ultra 晶片。雖然先前的 Linux 核心版本已為識別 M3 奠定基礎，但系統仍無法處理主儲存。在沒有可用 NVMe 驅動程式的情況下，在這些機器上安裝 Linux 仍停留在基本硬體識別階段，無法啟動至可用的作業系統或訪問主驅動器。</p>
<p>啟用 NVMe 是推進該平台發展的關鍵要求。成功整合這些補丁將使核心能夠與 M3 晶片上的快閃儲存控制器通訊，這是啟動和運行檔案系統的前提。此里程碑將討論重心，從初步的硬體發現，轉移到在 Apple 最新電腦上開發可啟動的、功能完備的 Linux 環境。</p>
<p>然而，補丁被指出存在一個重要的依賴關係。這些補丁被設計為與更新的 Apple 安全啟動管理器韌體配合工作。該韌體更新通常通過 macOS 軟件更新傳遞。因此，用戶需要確保其機器具有所需的韌體版本，核心級補丁才能正常運作，這是在 Apple 緊密整合的生態系統中常見的限制。</p>
<p>補丁目前正處於審查和測試階段，接受核心維護者和更廣泛開發者社區的嚴格審視。在真實 M3 硬體上進行社區驗證是關鍵的下一步。擁有基於 M3 的 Mac 的開發者和愛好者將在測試補丁、報告錯誤以及確保跨越多樣 M3 配置的穩定性方面扮演重要角色。</p>
<p>此進展是為 Apple Silicon 帶來完整 Linux 支援的持續、漸進式努力的一部分。雖然在 M3 上獲得精緻的日常使用體驗仍是未來目標，但每一個啟用核心組件（如儲存）的上游補丁，都使社區更進一步。對於旨在在最新 Apple 硬體上構建或實驗 Linux 的開發者和愛好者而言，啟用 NVMe 是解鎖進一步工作之門的關鍵鑰匙。</p>
