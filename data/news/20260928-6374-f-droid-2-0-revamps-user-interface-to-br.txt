Title: F-Droid 2.0 Revamps User Interface to Bridge Gap Between Open-Source Ideals and Mainstream Usability
Content:
<p>The F-Droid project, which provides an alternative app store focused exclusively on free and open-source software (FOSS), has launched version 2.0 of its official Android application. The F-Droid team describes the release as a complete redesign of the official app.</p>
<p>According to the announcement, as covered by LWN.net, the overhaul centres on improving how users discover and install software. Key changes include a revamped discovery experience, more useful application categories, and improved search functionality. The project has maintained its repository for over a decade, offering transparently auditable builds independent of Google's ecosystem.</p>
<p>The redesign addresses the app's interface and navigation, aiming to make the platform more approachable. F-Droid's repository continues to host exclusively FOSS applications, upholding its commitments to transparency and user freedom.</p>
<p>For existing users, updating to version 2.0 requires enabling beta updates within the current F-Droid client. Users should search for "F-Droid" in the client and toggle "Allow beta updates." New users can download the installer from the official F-Droid website, though the main download page currently still serves version 1.23.2.</p>
<p>The F-Droid project positions this release as a significant step in making the platform more accessible to a wider audience while maintaining its core principles of privacy, auditability, and user control over their Android devices.</p>

<p>專門提供自由及開源軟件（FOSS）替代應用程式商店的 F-Droid 項目，已推出其官方 Android 應用程式的 2.0 版本。F-Droid 團隊將此次發布描述為官方應用程式的完全重新設計。</p>
<p>根據 LWN.net 報導的公告，此次翻新主要集中在改善用戶發現和安裝軟件的方式。主要改進包括全新的發現體驗、更有用的應用程式分類，以及改進的搜尋功能。該項目已維護其程式庫超過十年，提供獨立於 Google 生態系統、可透明審計的構建版本。</p>
<p>重新設計針對應用程式的介面和導航，旨在使平台更易於使用。F-Droid 的程式庫繼續專門託管 FOSS 應用程式，堅持其對透明度和用戶自由的承諾。</p>
<p>對於現有用戶，更新至 2.0 版本需要在目前的 F-Droid 用戶端內啟用測試版更新。用戶應在用戶端內搜尋「F-Droid」並切換「允許測試版更新」選項。新用戶可從 F-Droid 官方網站下載安裝程式，但主要下載頁面目前仍提供 1.23.2 版本。</p>
<p>F-Droid 項目將此次發布定位為在讓平台更易於廣大受眾使用的同時，維護其在隱私、可審計性以及用戶對 Android 設備控制權方面核心原則的重要一步。</p>
