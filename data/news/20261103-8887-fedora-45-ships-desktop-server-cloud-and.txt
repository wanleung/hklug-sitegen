Title: Fedora 45 ships desktop, server, cloud and CoreOS editions in a single release
Content:
<p>Fedora Linux 45 has been released, with the project's editions arriving together in a single coordinated rollout — among them Fedora Workstation, Fedora KDE Plasma Desktop, Fedora Server, Fedora Cloud and Fedora CoreOS.</p>
<p>LWN.net reported the release on November 3, 2026, noting that Fedora 45 "includes all editions". The Atomic Desktops are also part of the release, according to the announcement.</p>
<p><strong>A release that spans the whole stack</strong></p>
<p>Fedora 45 covers desktop, server and cloud use cases under one release. Fedora Workstation is the project's GNOME-based desktop edition, while the KDE Plasma Desktop edition offers the same release cycle with KDE as the default environment. Fedora Server targets conventional server deployments, Fedora Cloud provides images for public-cloud use, and Fedora CoreOS is the project's minimal, auto-updating OS for container and cluster environments.</p>
<p>Also part of the release are the Atomic Desktops — immutable variants of the desktop experience in which the base operating system is delivered as a single, atomically updated image and applications are layered on top through container-based packaging. The immutable model replaces ad-hoc system modification with reproducibility and easier rollback, an update model used across Linux distributions on both workstations and servers.</p>
<p><strong>What changes in Fedora 45</strong></p>
<p>Two concrete changes accompany the release. The installer now supports installing onto Stratis storage through Anaconda and Kickstart, giving administrators an additional thin-provisioning storage option at install time. The release also retires a number of unmaintained NetworkManager VPN plugins, removing components that no longer had active maintainers upstream.</p>
<p><strong>A single baseline across editions</strong></p>
<p>Shipping the editions together means Fedora 45 provides one common baseline across the project's desktop and infrastructure products. Teams that follow Fedora releases as an early read on upstream Linux development can compare Fedora 45's server, cloud and immutable desktop offerings within the same release cycle.</p>
<p><strong>Support window and upgrade path</strong></p>
<p>Fedora maintains a schedule of overlapping numbered releases, and administrators responsible for Fedora 45 deployments should confirm the exact support window and end-of-life dates against Fedora's official lifecycle documentation before committing to upgrade timelines. The LWN report did not itemise kernel, toolchain or desktop component versions for this release.</p>
<p>With Fedora 45's desktop, server, cloud and immutable-infrastructure editions now shipping together, developers and sysadmins have a single release to evaluate across the project's product line.</p>

<p>Fedora Linux 45 已正式發布，項目各版本以一次統一協調的推出方式同步面世，其中包括 Fedora Workstation、Fedora KDE Plasma Desktop、Fedora Server、Fedora Cloud 及 Fedora CoreOS。</p>
<p>LWN.net 於 2026 年 11 月 3 日報道是次發布，指 Fedora 45「包含所有版本」。據公布所述，Atomic Desktops 亦是是次發布的一部分。</p>
<p><strong>一次涵蓋整個技術堆疊的發布</strong></p>
<p>Fedora 45 在單一發布中涵蓋桌面、伺服器及雲端應用場景。Fedora Workstation 是該項目的 GNOME 桌面版本，而 KDE Plasma Desktop 版本則在相同發布周期內以 KDE 作為預設環境。Fedora Server 針對傳統伺服器部署，Fedora Cloud 提供適用於公有雲的映像，Fedora CoreOS 則是該項目為容器及叢集環境而設的精簡自動更新作業系統。</p>
<p>是次發布亦包括 Atomic Desktops——桌面體驗的 immutable 變體，其基礎作業系統以單一映像形式交付並以原子方式更新，應用程式則透過 container 打包方式疊加其上。immutable 模式以可重現性及更輕鬆的回滾取代臨時性的系統修改，這種更新模式已應用於 Linux 各發行版的工作站及伺服器。</p>
<p><strong>Fedora 45 的具體改動</strong></p>
<p>是次發布帶來兩項具體變更。安裝程式現可透過 Anaconda 及 Kickstart 安裝至 Stratis 儲存裝置，為系統管理員在安裝時多提供一個精簡配置（thin-provisioning）的儲存選項。發布同時移除多個不再有人維護的 NetworkManager VPN 插件，剔除上游已沒有活躍維護者的組件。</p>
<p><strong>各版本之間的共同基準</strong></p>
<p>各版本同步推出，意味著 Fedora 45 在該項目的桌面及基礎設施產品之間提供單一共同基準。透過追蹤 Fedora 發布以前瞻 Linux 上游開發動向的團隊，可在同一發布周期內比較 Fedora 45 的伺服器、雲端及 immutable 桌面產品。</p>
<p><strong>支援周期及升級路徑</strong></p>
<p>Fedora 維持編號版本重疊發布的時間表，負責 Fedora 45 部署的系統管理員應在確定升級時間表前，先對照 Fedora 官方生命週期文件核實確切的支援周期及支援終止日期。LWN 的報道未有逐項列出是次發布的 kernel、toolchain 及桌面組件版本。</p>
<p>隨著 Fedora 45 的桌面、伺服器、雲端及 immutable 基礎設施版本同步推出，開發者及系統管理員可透過單一發布版本評估該項目整個產品線。</p>
