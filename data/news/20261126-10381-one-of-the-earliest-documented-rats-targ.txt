Title: One of the Earliest Documented RATs Targets LoongArch Linux, With Rust Implant Extending to macOS
Content:
<h3>One of the Earliest Documented RATs Targets LoongArch Linux, With Rust Implant Extending to macOS</h3>
<p>A remote access trojan written to run on LoongArch — a homegrown CPU architecture promoted by China's Loongson Technology as an alternative to x86 and ARM — has been identified as one of the earliest publicly documented RATs targeting that platform, according to an analysis published by Security Affairs and based on primary research by the MalwareMustDie collective.</p>
<p>The implant, tracked as Linux/EasyShell, is written in Rust and supports both Linux and macOS — a dual-target design that points to cross-compilation rather than a single-platform build. LoongArch, developed by Loongson Technology, is the instruction set architecture intended to reduce domestic reliance on Western silicon designs; security tooling and telemetry built around x86 and ARM have historically offered far thinner coverage for it, which makes a working implant for the platform a notable data point for defenders.</p>
<h4>From shell script to implant</h4>
<p>The case did not begin with a sample handed to analysts. MalwareMustDie researchers traced it back to a shell script found on a victim's node, with the original discovery credited to the researcher 0xrb. The collective's researcher first read the script as one more miner-style uninstaller or downloader — the sort of low-signal noise that fills most malware queues. It wasn't.</p>
<p>The script turned out to be an installer for a full-featured implant, complete with stealth characteristics designed to evade detection. Neither Security Affairs nor MalwareMustDie's write-up names the threat actor behind the campaign. That absence matters: the technical record currently supports what the code does, not who is running it.</p>
<h4>Why it warrants attention</h4>
<p>Two features make EasyShell worth tracking beyond its novelty. First, LoongArch support suggests someone is investing in offensive tooling for an architecture that has received comparatively little malware attention — coverage that will only grow as the platform spreads through mainland deployments. Second, the Rust implementation, cross-compiled to reach both Linux servers and macOS endpoints, reflects the broader shift in modern malware away from C-based tooling toward languages that make portability and evasion cheaper to engineer.</p>
<p>For open-source and Linux administrators, the practical takeaway is unglamorous but consistent with recent incidents: a script found on a node that looks like disposable cryptomining debris can be the entry point to a purpose-built implant. Detection signatures and IOC lists are not reproduced here; readers seeking indicators should consult MalwareMustDie's primary analysis directly, as relayed by Security Affairs.</p>
<p>As of this writing, no named actor has been publicly attributed — and readers should check MalwareMustDie's primary write-up for any subsequent updates on attribution or victimology.</p>

<h3>最早有紀錄的 RAT 之一鎖定 LoongArch Linux，Rust implant 更延伸至 macOS</h3>
<p>據 Security Affairs 刊出、基於 MalwareMustDie 集體一手研究的分析顯示，一個專為在 LoongArch 上運行而編寫的 remote access trojan（遠端存取木馬，RAT），已被確認為最早公開有紀錄、鎖定該平台的 RAT 之一。LoongArch 是由中國龍芯科技（Loongson Technology）力推、用以取代 x86 及 ARM 的國產 CPU 架構。</p>
<p>該 implant 標記為 Linux/EasyShell，以 Rust 編寫，同時支援 Linux 及 macOS——這種雙目標設計反映其透過 cross-compilation 建置，而非單一平台建置（build）。LoongArch 由龍芯科技開發，是指令集架構，旨在減少國內對西方矽片設計的依賴；歷來圍繞 x86 及 ARM 建立的安全工具及 telemetry 對其覆蓋一直薄弱得多，因此一個能在該平台運作的 implant，對防禦者而言是一個值得注目的數據點。</p>
<h4>由 shell script 到 implant</h4>
<p>案件並非始於有人把樣本交到分析員手上。MalwareMustDie 研究人員順線追查至受害節點上發現的一個 shell script，最初的發現歸功於研究員 0xrb。該集體的研究人員起初把 script 視為又一個 miner 式的卸載程式或下載器——即充斥大多數惡意軟件隊列的低訊號噪音。結果並非如此。</p>
<p>該 script 終被證實是一個功能齊全的 implant 的安裝程式，並具備旨在規避偵測的隱匿特性。Security Affairs 及 MalwareMustDie 的技術文章均未有披露該行動背後的威脅行為者。這點至關重要：現有的技術紀錄只能說明代碼的行為，而非誰在操縱它。</p>
<h4>為何值得關注</h4>
<p>EasyShell 有兩項特點令其超越新奇性而值得持續追蹤。第一，支援 LoongArch 顯示已有人為一種歷來甚少受惡意軟件關注的架構投入 offensive tooling——隨著該平台在中國大陸部署中擴張，這種覆蓋只會增加。第二，以 Rust 實作並 cross-compile 至 Linux 伺服器及 macOS 終端，反映出現代惡意軟件的整體轉變：由以 C 為基礎的工具，轉向令可攜性及規避能力更易於工程實現的語言。</p>
<p>對開源及 Linux 系統管理員而言，實務上的啟示平淡無奇，卻與近期事件一致：節點上一個看似即棄 cryptomining 廢料的 script，可以是一個專門製造的 implant 的入口點。本文未有轉載偵測 signatures 及 IOC 名單；讀者如需 indicators，應直接查閱 MalwareMustDie 的一手分析，即 Security Affairs 所轉述的版本。</p>
