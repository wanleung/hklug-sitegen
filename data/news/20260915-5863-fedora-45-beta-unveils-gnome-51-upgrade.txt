Title: Fedora 45 Beta Unveils GNOME 51 Upgrade and a Modernized KMSCON Console
Content:
<p>Fedora 45 Beta launched today, inviting developers and system administrators to begin testing significant updates to both the desktop experience and the underlying console system.</p>
<p>The release includes <strong>GNOME 51</strong>, the latest iteration of the default desktop environment. This update continues recent efforts to refine performance and stability, with polish applied to core applications. For those maintaining workstation deployments, these incremental improvements can meaningfully reduce friction in daily use.</p>
<p>For sysadmins and power users, the more significant change is the introduction of <strong>KMSCON</strong>, a modern user-space console implementation intended to replace the traditional kernel console. KMSCON brings a graphical, high-resolution text console with Unicode support and mouse cursor integration—a quality-of-life upgrade for managing multi-user systems or performing text-based administration requiring complex character sets.</p>
<p>The Fedora Project is positioning this beta as a critical community testing phase. According to the announcement, users can download Fedora 45 Beta from official project Spins and are encouraged to validate hardware compatibility—particularly for the new KMSCON subsystem—and to report issues ahead of the final release later this year.</p>
<p>Fedora has long served as an incubator for technologies that propagate across the broader Linux ecosystem. With both a major desktop environment refresh and a foundational console overhaul landing in the same release, Fedora 45 represents a notable step forward for the platform. Testers and contributors are encouraged to participate in shaping the stable release.</p>
<hr>
<p>Fedora 45 Beta 於今日推出，邀請開發者和系統管理員開始測試桌面體驗與底層控制台系統的重大更新。</p>
<p>此版本包含 <strong>GNOME 51</strong>，即預設桌面環境的最新迭代版本。此更新延續了近期對效能和穩定性的精煉工作，並對核心應用程式進行了優化。對於維護工作站部署的人員而言，這些漸進式的改進可顯著減少日常使用中的阻力。</p>
<p>對系統管理員和高級用戶而言，更重要的變動是引入了 <strong>KMSCON</strong>——一個旨在取代傳統核心控制台的現代化用戶空間控制台實現。KMSCON 帶來了一個圖形化、高解析度的文字控制台，具備 Unicode 支援與滑鼠游標整合功能，為管理多用戶系統或執行需要複雜字元集的文字管理作業提供了品質上的升級。</p>
<p>Fedora 項目將此測試版定位為關鍵的社群測試階段。據公告所述，用戶可從官方項目 Spin 下載 Fedora 45 Beta，並鼓勵驗證硬件相容性——尤其是針對新的 KMSCON 子系統——並在今年稍後的最終版本發佈前回報問題。</p>
<p>Fedora 長期以來一直是技術的孵化器，這些技術最終會在更廣泛的 Linux 生態系統中傳播。隨著重大的桌面環境更新和基礎性的控制台革新在同一次版本中登場，Fedora 45 代表了該平台一個顯著的進步。測試人員和貢獻者鼓勵參與塑造穩定版本。</p>
