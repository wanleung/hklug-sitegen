Title: NVIDIA's 615.78.08 Linux Driver Adds r3 of Its Low-Latency Vulkan Extension for Proton
Content:
<p>Phoronix reports that NVIDIA has released a new Linux driver build, version 615.78.08, targeting Direct3D 12 titles running through Proton, Steam Play's compatibility layer. According to the report, the update adds a third revision of the company's low-latency Vulkan extension — VK_NV_low_latency2 r3 — alongside a number of other fixes.</p>
<h4>What's in the update</h4>
<p>Phoronix identifies the r3 revision of VK_NV_low_latency2 as the main change, and says it was written specifically to improve VKD3D-Proton. VKD3D-Proton is the translation layer that converts Direct3D 12 calls into Vulkan, and it sits between a Windows-native DX12 game and a Linux desktop. A low-latency path the layer can use could improve frame pacing and input responsiveness, though real-world benchmarks will determine the actual impact.</p>
<p>The release also includes fixes for driver crashes.</p>
<h4>Why it matters for Proton users</h4>
<p>The change targets gamers running DX12 titles through Steam Play. VKD3D-Proton has been the weaker link in that chain compared with the more mature DX11 translation path; each revision of the underlying driver support that the layer can use narrows the gap between the Windows and Linux experience.</p>
<p>The update also keeps the stack moving in lockstep. VKD3D-Proton development and NVIDIA's Vulkan extension revisions are separate tracks maintained by separate parties, but they only deliver value when they meet in a shipped driver. A user running an older driver build cannot expose r3 functionality to the translation layer, no matter how current their Proton or VKD3D-Proton version is.</p>
<h4>Availability and packaging</h4>
<p>Phoronix reports that the 615.78.08 build is available through NVIDIA's usual channels, with packaging covering supported Linux distributions and kernel versions, and release notes published alongside the download.</p>
<p>The crash fixes matter most to users running NVIDIA hardware in long-lived desktop or workstation setups.</p>
<p>The update is an incremental release for desktop Linux users already on a recent branch, and the new functionality activates only for applications that know to use it.</p>

<hr>
<p>據 Phoronix 報道，NVIDIA 發佈新版 Linux 驅動 615.78.08，針對透過 Proton（Steam Play 的相容層）執行的 Direct3D 12 遊戲。該報道指，更新加入了該公司低延遲 Vulkan 擴充的第三個修訂版——VK_NV_low_latency2 r3——以及其他多項修復。</p>
<h4>更新內容</h4>
<p>Phoronix 將 VK_NV_low_latency2 的 r3 修訂版列為主要改動，並指該版本編寫目的是專門改進 VKD3D-Proton。VKD3D-Proton 是將 Direct3D 12 呼叫轉換為 Vulkan 的翻譯層（translation layer），位於 Windows 原生 DX12 遊戲與 Linux 桌面系統之間。該層可用的低延遲路徑或可改善幀率穩定性（frame pacing）及輸入反應速度，實際影響仍須視乎基準測試結果而定。</p>
<p>是次發佈亦包含驅動崩潰的修復。</p>
<h4>對 Proton 用戶的意義</h4>
<p>相關改動針對透過 Steam Play 執行 DX12 遊戲的玩家。相比較成熟的 DX11 翻譯路徑，VKD3D-Proton 一直是整條鏈中較薄弱的一環；翻譯層每當能利用底層驅動支援的新修訂版，Windows 與 Linux 遊戲體驗之間的差距便會收窄。</p>
<p>更新亦讓整個技術堆疊同步推進。VKD3D-Proton 的開發與 NVIDIA 的 Vulkan 擴充修訂屬不同機構維護的獨立路線，但只有在隨驅動正式發佈並匯合時，才能發揮價值。用戶若使用舊版驅動，無論其 Proton 或 VKD3D-Proton 版本有多新，翻譯層都無法呼叫 r3 功能。</p>
<h4>可用性與安裝套件</h4>
<p>據 Phoronix 報道，615.78.08 版本已透過 NVIDIA 常規渠道提供，安裝套件涵蓋受支援的 Linux 發行版與核心版本，發佈說明亦隨下載一同刊出。</p>
<p>是次發佈的崩潰修復，對在長期運作的桌面或工作站配置上使用 NVIDIA 硬件的用戶尤為重要。</p>
<p>是次更新屬漸進式版本，適用於已在近期版本分支上的 Linux 桌面用戶，新功能只會對知悉如何使用的應用程式啟用。</p>
