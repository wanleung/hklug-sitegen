Title: Canonical Revives Ubuntu Core Desktop After Two-Year Hiatus
Content:
<p>Canonical is reviving Ubuntu Core Desktop, the immutable Linux desktop its engineers first outlined in 2023. The project made early progress before going quiet from 2024 onward, according to Phoronix.</p>
<p>Canonical engineers laid out plans for Ubuntu Core Desktop in 2023, framing it as the company's immutable desktop offering, and the project picked up real momentum in its early months. From 2024 onward, updates dried up and the effort went quiet — a silence now lasting roughly two years. Phoronix reports that Canonical is restarting the work, with ambitious plans for the distribution's future.</p>
<p>The earlier effort stalled without explanation, and Phoronix's reporting does not indicate that the revived project has been given a shipping target date. No dates have been published to plan against.</p>
<h5>What "immutable desktop" actually means</h5>
<p>Ubuntu Core Desktop belongs to a family of distributions built on the principle that the underlying OS image is read-only. Users do not modify the base system package-by-package as they would on a conventional Debian or Ubuntu install. Instead, updates are applied atomically to the whole image, and reverting to a previous snapshot is a matter of switching back rather than untangling a partial upgrade. Applications are delivered as self-contained, sandboxed units — in Canonical's case, snaps, the company's long-standing packaging format that already powers Ubuntu Core, its minimal, transactionally-updated server and IoT platform.</p>
<p>That framing is what makes this a "Core" product: Ubuntu Core is Canonical's embedded and appliance line, and the desktop variant extends the same transactional update model to a workstation environment.</p>
<h5>Where it sits against the field</h5>
<p>Canonical would not be first to market. Fedora Silverblue and openSUSE MicroOS have shipped immutable desktop experiences for several years — Silverblue leaning on rpm-ostree, MicroOS on openSUSE's transactional-update with btrfs snapshots — each managing atomic system updates while letting users layer traditional packages on top when they need to. Immutable desktops have also found a foothold in gaming — Valve's SteamOS, built on an immutable Arch-based base with a Flatpak-centric app layer, has arguably done more than anything else to normalise the model for non-technical users.</p>
<p>What Canonical brings is enterprise footprint: an install base, commercial support, and a certification channel that the more community-driven immutable distros lack.</p>
<h5>The caveat</h5>
<p>Taken together, the picture is a familiar one for open-source projects: Canonical has revived the project, not yet delivered it, and no dated roadmap has been published. Three years after it was first sketched, and two years after it went quiet, Ubuntu Core Desktop remains a project in development rather than a product.</p>

<h5>「不可變桌面」到底是什麼意思</h5>
<p>Ubuntu Core Desktop 屬於一類以「底層作業系統映像只讀」為原則構建的發行版。用戶並非像在傳統 Debian 或 Ubuntu 安裝中那樣逐個軟件包地修改基礎系統，而是以原子方式（atomic）對整個映像進行更新；如需回復先前版本，只需切換回原有快照，無需處理不完整的升級。應用程式則以自包含、沙盒化的單元形式交付——對 Canonical 而言即是 snap，這是該公司沿用已久的打包格式，目前已驅動 Ubuntu Core，即其採用交易式更新的精簡伺服器與 IoT 平台。</p>
<p>正是這種定位使它成為「Core」產品：Ubuntu Core 是 Canonical 的嵌入式及專用設備產品線，而桌面版本則將同一套交易式更新模型延伸至工作站環境。</p>
<h5>在同類產品中的位置</h5>
<p>Canonical 並非市場先行者。Fedora Silverblue 與 openSUSE MicroOS 已推出不可變桌面體驗數年——Silverblue 倚賴 rpm-ostree，MicroOS 則採用 openSUSE 以 btrfs 快照為基礎的 transactional-update——兩者均能管理原子式系統更新，同時在用戶需要時允許在其上疊加傳統軟件包。不可變桌面在遊戲領域也已找到立足之地——Valve 的 SteamOS 底層採用不可變的 Arch 系統，應用層則以 Flatpak 為核心，可以說比任何其他因素都更有效地令這種模式在非技術用戶中變得普及。</p>
<p>Canonical 帶來的優勢在於企業級版圖：安裝基礎、商業支援，以及較為社區驅動的不可變發行版所欠缺的認證渠道。</p>
<h5>保留事項</h5>
<p>總括而言，這是開源項目屢見不鮮的局面：Canonical 已重啟項目，但尚未交付成果，亦未公布附有日期的路線圖。距離首次勾勒雛形已三年、歸於沉寂已兩年，Ubuntu Core Desktop 仍然只是開發中的項目，而非產品。</p>
