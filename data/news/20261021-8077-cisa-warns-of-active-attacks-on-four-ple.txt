Title: CISA warns of active attacks on four Plex Media Server flaws
Content:
<h4>News in brief</h4>
<p>Attackers are actively exploiting four vulnerabilities in Plex Media Server, according to a warning from the U.S. Cybersecurity and Infrastructure Security Agency (CISA) reported by BleepingComputer. The report describes the four bugs as being used in combination to reach code execution on internet-facing hosts, rather than exploited one at a time. CISA has flagged the flaws for patching.</p>
<p>Plex Media Server typically runs on always-on hardware — NAS units, desktop machines and small virtual private servers — so a compromised instance hands an intruder a foothold inside a network rather than a broken media player. The same boxes that stream films often also hold shared file stores, credentials and backups.</p>
<p>Operators should update Plex Media Server from official channels, restart the service so the fix reaches the running process, and audit router port-forwarding, reverse proxies and NAS control panels for Plex endpoints exposed to the public internet without good reason.</p>
<p>Severity ratings assess bugs one at a time; attackers do not. A full version of this report, including CVE identifiers and a patched-version table, will follow once those details are confirmed against primary sources.</p>

<h4>新聞摘要</h4>
<p>據 BleepingComputer 報道，美國網絡安全和基礎設施安全局（CISA）發出警告，指攻擊者正積極利用 Plex Media Server 的四項漏洞。報道指這四個漏洞被串聯組合使用，以在面向互聯網的主機上實現 code execution，而非逐個獨立利用。CISA 已就相關漏洞發出修補呼籲。</p>
<p>Plex Media Server 通常在長期開機的硬件上運行——包括 NAS 裝置、桌面電腦及小型 virtual private server——因此一個被入侵的實例會為闖入者提供網絡內的立足點，而不只是一部損壞的媒體播放器。同樣這些用來串流影片的設備，往往也存放著共享檔案庫、憑證及備份。</p>
<p>營運者應透過官方渠道更新 Plex Media Server，並重啟相關服務，確保修補套用至運行中的程序；同時審核路由器 port forwarding、reverse proxies 及 NAS 控制面板，檢查是否有 Plex 端點在無合理理由下暴露於公眾互聯網。</p>
<p>（編按：漏洞嚴重性評級是逐個評估的，但攻擊者往往會將多個漏洞串聯利用。本文報導的完整版本，包括 CVE 編號及已修補版本對照表，將在相關細節對照一手來源確認後刊出。）</p>
