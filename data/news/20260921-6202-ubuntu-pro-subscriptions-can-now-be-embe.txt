Title: Ubuntu Pro Subscriptions Can Now Be Embedded Directly in AWS Image Builder Recipes
Content:
<p>Canonical has announced that Ubuntu Pro subscriptions can now be attached directly to base images within AWS Image Builder, allowing users to create enterprise-grade custom images with built-in support from the start.</p>
<h4>New Integration Simplifies Image Configuration</h4>
<p>Previously, applying an Ubuntu Pro subscription to an image built with AWS Image Builder required manually entering a token during the build process. The new integration streamlines this by allowing administrators to specify their Ubuntu Pro subscription credentials when defining an image recipe within AWS Image Builder.</p>
<p>AWS Image Builder is a managed AWS service that automates the creation of custom Amazon Machine Images (AMIs). With this update, custom images produced through the service are configured as enterprise-grade from the outset, according to Canonical's announcement.</p>
<p>Ubuntu Pro provides access to security patching, livepatching for kernel updates, and compliance hardening features. By attaching a subscription at the image definition stage, organizations can ensure that every instance launched from the resulting AMI carries Ubuntu Pro coverage.</p>
<h4>Implementation Details</h4>
<p>The feature is available in all regions where AWS Image Builder operates. Configuration is supported via the AWS Management Console and the Command Line Interface (CLI).</p>
<p>DevOps teams seeking to implement this should consult the official AWS Image Builder documentation for recipe configuration and Canonical's guide for entering subscription details.</p>
<hr>
<p>Canonical 宣布 Ubuntu Pro 訂閱現可直接附加到 AWS 映像檔建構器中的基礎映像檔，讓用戶從一開始就能建立內建支援的企業級自訂映像檔。</p>
<h4>新整合簡化映像檔配置</h4>
<p>此前，將 Ubuntu Pro 訂閱應用於使用 AWS 映像檔建構器建立的映像檔，需要在建構過程中手動輸入令牌。新的整合方式透過允許管理員在 AWS 映像檔建構器中定義映像檔配方時指定其 Ubuntu Pro 訂閱憑證，簡化了此流程。</p>
<p>AWS 映像檔建構器是一項託管 AWS 服務，可自動化建立自訂 Amazon 機器映像檔 (AMI)。根據 Canonical 的公告，透過此服務產生的自訂映像檔從一開始即配置為企業級。</p>
<p>Ubuntu Pro 提供安全修補、核心更新即時修補 (livepatching) 以及合規性強化功能。透過在映像檔定義階段附加訂閱，組織可以確保從生成的 AMI 啟動的每個實例都攜帶 Ubuntu Pro 涵蓋。</p>
<h4>實施詳情</h4>
<p>此功能在 AWS 映像檔建構器運作的所有區域均可使用。支援透過 AWS 管理主控台及命令列界面 (CLI) 進行配置。</p>
<p>希望實施此功能的 DevOps 團隊應參閱 AWS 映像檔建構器官方文件以了解配方配置，並參考 Canonical 的指南以輸入訂閱詳情。</p>
