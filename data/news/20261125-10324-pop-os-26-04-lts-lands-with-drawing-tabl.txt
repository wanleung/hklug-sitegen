Title: Pop!_OS 26.04 LTS lands with drawing-tablet support and automatic updates
Content:
<p>System76 has released Pop!_OS 26.04 LTS, the long-term support release of its Ubuntu-based desktop distribution, LWN.net reported. The new version is built on Ubuntu 26.04 LTS and brings drawing-tablet support, automatic updates, and a number of new applications for the COSMIC desktop environment.</p>
<h4>LTS base and support window</h4>
<p>As an even-numbered LTS release, 26.04 is positioned as the natural target for new deployments and for teams that anchor provisioning cycles to the Ubuntu LTS cadence. LWN's report did not restate a Pop!_OS-specific support schedule, so organisations standardising on 26.04 should confirm the distribution's own support window directly with System76 before committing to it.</p>
<h4>What's new in this release</h4>
<p>Drawing-tablet support is the headline hardware feature, a welcome addition for artists and designers who want pressure-sensitive pen input available out of the box.</p>
<p>Equally significant for day-to-day administration is the addition of automatic updates. If the promise of security patches applied without user intervention holds up in practice, it is a notable change — and a genuine convention shift on desktop Linux. Administrators and users who habitually review packages before applying them should check the new behaviour rather than assume the old manual workflow still applies, particularly on shared or managed machines.</p>
<p>COSMIC, System76's Rust-based desktop environment, continues to fill out its application roster. The release builds on COSMIC's existing core applications with a further batch of new first-party apps as the desktop matures. Whether COSMIC has reached daily-use polish remains the real barometer for adopters: each LTS release serves as a measurable checkpoint on the homegrown Rust desktop's progress.</p>
<h4>Upgrading from 24.04: wait until December</h4>
<p>The most practical takeaway concerns timing. In-place updates for users running Pop!_OS 24.04 LTS will not be enabled until December, meaning 26.04 is not upgrade-ready for existing installations for most of the remainder of the year. The prudent course is to wait for that window and back up beforehand; a clean install is worth considering if the system carries heavy customisation, as in-place upgrades across two LTS generations are where most problems originate.</p>
<h4>Availability</h4>
<p>Installation images are available now from System76's website.</p>
<h4>Perspective</h4>
<p>Two things deserve watching. First, automatic updates as a standard offering moves Pop!_OS closer to the appliance-like behaviour of mainstream consumer operating systems; whether the COSMIC ecosystem's target audience embraces or resists that shift will say something about desktop Linux's broader direction. Second, the health of COSMIC matters beyond Pop!_OS — it is one of the few serious attempts to build a modern desktop from scratch rather than fork an existing one, and each LTS release is a measurable checkpoint on that project's progress.</p>
<p>A follow-up when the December upgrade window opens would be a natural point to assess how the 24.04 to 26.04 path actually performs in practice.</p>

<p>據 LWN.net 報道，System76 已發佈 Pop!_OS 26.04 LTS，這是其基於 Ubuntu 的桌面發行版的長期支援版本。新版本建基於 Ubuntu 26.04 LTS，加入繪圖板支援、自動更新，以及多款適用於 COSMIC 桌面環境的新應用程式。</p>
<h4>LTS 基礎及支援期</h4>
<p>作為雙數 LTS 版本，26.04 被定位為新部署的自然目標，亦適合將部署週期與 Ubuntu LTS 節奏掛鈎的團隊。LWN 的報道並未重申 Pop!_OS 專屬的支援時間表，因此計劃以 26.04 作為標準化的機構，應先直接向 System76 確認該發行版本身的支援期，才作出承諾。</p>
<h4>本版本的新增功能</h4>
<p>繪圖板支援是本版本最主要的硬件功能，對希望開箱即用即可使用壓力感應筆輸入的藝術家及設計師而言，是一項值得歡迎的新增功能。</p>
<p>對日常系統管理同樣重要的，是自動更新的加入。若保安修補程式無須用戶干預即可套用的承諾在實踐中成立，這將是一項顯著的改變——對桌面 Linux 而言亦屬慣例上的真正轉變。習慣在套用套件前逐一檢視的管理員及用戶，應留意新的行為，而非假設舊有的手動流程仍然適用，尤其是在共用或受管理的機器上。</p>
<p>System76 以 Rust 開發的桌面環境 COSMIC，其應用程式陣容持續擴充。本版本在 COSMIC 既有核心應用程式之上，隨著桌面日趨成熟，再加入一批全新的第一方應用程式。COSMIC 是否已達至可日常使用的成熟度，仍是採用者真正的衡量標準：每個 LTS 版本都是這款自家研發 Rust 桌面進度的可量度檢視點。</p>
<h4>由 24.04 升級：請等到十二月</h4>
<p>最實際的要點涉及時機。執行 Pop!_OS 24.04 LTS 的用戶，原地升級要到十二月才會啟用，這意味著在今年餘下的大部分時間內，26.04 尚未為現有安裝作好升級準備。穩妥的做法是等待該窗口開啟，並事先備份；若系統有大量自訂設定，則值得考慮全新安裝，因為跨兩個 LTS 版本的原地升級正是大多數問題的根源。</p>
<h4>取得方式</h4>
<p>安裝映像現已可在 System76 網站下載。</p>
<h4>評論</h4>
<p>有兩點值得關注。第一，自動更新成為標準功能，使 Pop!_OS 更接近主流消費級作業系統如家電般的行為模式；COSMIC 生態系統的目標用戶會擁抱還是抗拒這一轉變，將反映桌面 Linux 的整體發展方向。第二，COSMIC 的健康狀況其影響不限於 Pop!_OS——它是少數認真嘗試從頭構建現代桌面、而非分叉既有桌面的項目之一，每個 LTS 版本都是該項目進度的可量度檢視點。</p>
<p>待十二月升級窗口開啟後再作跟進，將是評估 24.04 至 26.04 升級路徑實際表現的恰當時機。</p>
