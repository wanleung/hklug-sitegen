Title: Microsoft Makes Linux Containers on Windows Native, Eliminating the Virtualization Layer
Content:
<p>Microsoft has announced the general availability of Windows Subsystem for Linux Containers (WSLC), a significant architectural update that enables Linux containers to run as native processes within the WSL 2 kernel on Windows. This shift eliminates the performance overhead of a dedicated virtual machine, delivering faster startup times and lower memory usage for developers.</p>
<p>The move simplifies the "develop on Windows, deploy to Linux" workflow by removing a major layer of abstraction. Previously, container workloads required a separate Linux VM, even when using WSL. With WSLC GA, the container runtime integrates directly, offering a more seamless and efficient bridge between the two environments.</p>
<p>For the large population of Windows-based developers, this change reduces configuration complexity and makes cloud-native development more accessible. The updated toolchain allows for smoother building, testing, and running of containerized applications, including Kubernetes orchestration.</p>
<p>The announcement is bolstered by planned integration from key ecosystem partner Docker, ensuring the widely-used Docker Desktop will leverage the native WSLC runtime. This collaboration facilitates an easy transition for existing users and underscores the industry trend toward deeper native integration over virtualization.</p>
<p>Overall, WSLC GA lowers barriers for Windows-based teams to fully engage in container-native operations, potentially accelerating the adoption of modern development practices across the software lifecycle.</p>
<hr>
<p>微軟宣布正式發布Windows子系統Linux容器（WSLC），這是一項重大架構更新，使Linux容器能在Windows的WSL 2核心內以原生進程方式運行。此舉消除了專用虛擬機器帶來的性能開銷，為開發者帶來更快的啟動速度和更低的記憶體佔用率。</p>
<p>此項舉措透過移除主要的抽象層，簡化了「在Windows開發，部署至Linux」的工作流程。以往，即使使用WSL，容器工作負載仍需依賴獨立的Linux虛擬機器。隨著WSLC正式發布，容器運行時實現直接整合，在兩種環境之間構建了更無縫、更高效的橋樑。</p>
<p>對廣大的Windows開發者群體而言，此項變更降低了配置複雜度，使雲原生開發更易實現。更新後的工具鏈允許更順暢地建構、測試及運行容器化應用程式，包括Kubernetes協調編排。</p>
<p>此公告得到關鍵生態合作夥伴Docker計劃整合的支持，確保廣泛使用的Docker Desktop將能利用原生WSLC運行時。這項合作為現有用戶提供便捷過渡方案，並凸顯業界趨勢正從虛擬化轉向更深層的原生整合。</p>
<p>整體而言，WSLC正式發布降低了Windows開發團隊全面投入容器原生運維的門檻，有望加速軟體生命週期中現代開發實踐的普及。</p>
