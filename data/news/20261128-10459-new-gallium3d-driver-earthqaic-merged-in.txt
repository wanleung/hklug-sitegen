Title: New Gallium3D Driver 'Earthqaic' Merged Into Mesa for the 27.0 Cycle
Content:
<p>A brand-new Gallium3D driver called <strong>Earthqaic</strong> has been merged into Mesa Git ahead of the project's 27.0 development cycle, according to Phoronix, which reported the landing of the backend as it went upstream.</p>
<p>Earthqaic is a fresh addition to Mesa's driver stack rather than a rework of an existing one. Mesa is the open-source graphics library collection that supplies OpenGL, Vulkan and video acceleration for essentially every Linux desktop distribution; Gallium3D is the intermediate layer that sits between those application-facing APIs and the hardware-facing state trackers, letting driver authors implement the hard, hardware-specific parts once while sharing the plumbing. RadeonSI for AMD GPUs, RADV for AMD Vulkan, and Intel's ANV are all built on that framework, which is why the arrival of a genuinely new Gallium3D backend is notable: it is an implicit vote of confidence that the abstraction still pays for itself.</p>
<p>The timing is deliberate. Landing early in the 27.0 cycle gives the driver a full development window to be stabilised, reviewed and tested before it reaches users through distribution packages. Ubuntu, Fedora, Arch and the growing family of immutable distributions all track Mesa releases, so anything that merges cleanly now has a realistic path to end users over the coming release cycle — rather than being rushed in at freeze time.</p>
<p>What is not yet established, from the material available at the time of writing, is the hardware Earthqaic targets, who contributed it, and how feature-complete it is at merge. Those are the three questions that will determine whether this is a headline driver or groundwork for a future hardware generation. Until the upstream commit history and mailing-list discussion fill in those gaps, the honest description of the story is that the code exists, it is in mainline Mesa, and its practical scope is still being defined.</p>
<p>For Linux users and system integrators, the near-term impact is limited — no distribution is shipping Earthqaic as a default today, and no existing setup will change behaviour because of it. The longer-term signal is more interesting: Mesa's driver roster only expands when someone has a hardware target worth supporting through a full upstream lifecycle, and each new backend widens the set of GPUs that can be driven by an entirely open-source stack.</p>
<p>What we are watching as 27.0 progresses: whether the hardware target is named publicly in the commit or follow-up discussion; whether the driver is enabled by default in distribution builds or gated behind build flags; and how it benchmarks against established backends once there is silicon to run it on. The spellings, the merge cadence and the default-enablement decisions are all visible in Mesa Git and the project's mailing lists, and we will update this story as those details emerge.</p>

author: HKLUG Team

<hr />
<p>據 Phoronix 報導，名為 <strong>Earthqaic</strong> 的全新 Gallium3D 驅動程式已合併至 Mesa Git，趕在專案 27.0 開發週期正式展開之前落地。</p>
<p>Earthqaic 是 Mesa 驅動名單上的全新成員，而非既有驅動的改寫。Mesa 是開源圖形函式庫集合，為幾乎每一種 Linux 桌面發行版提供 OpenGL、Vulkan 與影片加速；Gallium3D 則是介於這些面向應用程式的 API 與面向硬件的狀態追蹤器之間的中間層，讓驅動開發者只需實作一次艱難的硬件特定部分，其餘管線則可共享。AMD GPU 的 RadeonSI、AMD Vulkan 的 RADV，以及 Intel 的 ANV 都建構於此框架之上——正因如此，一款真正全新的 Gallium3D 後端加入才值得關注：這等於為該抽象層仍然物有所值投下一票。</p>
<p>時機並非偶然。提早合併進 27.0 週期，為驅動預留了完整的開發窗口，得以在透過發行版套件抵達用戶之前完成穩定、審查與測試。Ubuntu、Fedora、Arch 以及日益增多的不可變（immutable）發行版都跟隨 Mesa 的發行節奏，因此任何現在乾淨合併的程式碼，在下一個發行週期都有實際抵達用戶的路徑，而不必在凍結前夕倉促趕工。</p>
<p>從寫作時可得的材料來看，尚未確定的是 Earthqaic 面向哪款硬件、由誰貢獻，以及合併時的功能完成度。這三個問題將決定它究竟是矚目的主力驅動，還是為未來硬件世代鋪路的基礎工作。在上游提交記錄與郵件列表討論補上這些空白之前，對這則新聞最誠實的描述是：程式碼存在，它已進入 Mesa 主線，其實際範圍仍在界定之中。</p>
<p>對 Linux 用戶與系統整合商而言，短期影響有限——目前沒有發行版預設出貨 Earthqaic，現有設定也不會因它而出現行為變化。較長期的訊號反而更有意思：Mesa 的驅動名單只在有人認為某項硬件目標值得投入完整上游生命週期時才會擴張，而每新增一個後端，都擴大了可以完全以開源架構驅動的 GPU 範圍。</p>
<p>隨著 27.0 週期推進，我們持續追蹤三件事：硬件目標會否在提交或後續討論中公開點名；驅動在發行版建置中是預設啟用，還是藏在編譯旗標之後；以及一旦有實體晶片可跑，它與既有後端的基準測試表現如何。拼寫、合併節奏與預設啟用與否，都可在 Mesa Git 與專案郵件列表中查證，隨著細節浮現，我們會持續更新本文。</p>
