Title: Ubuntu 26.10 'Stonking Stingray' ships quantum-safe package signing and a fully Rust coreutils
Content:
<p>Canonical today released Ubuntu 26.10, codenamed "Stonking Stingray," the latest interim build of its Linux distribution, available to download from ubuntu.com/download. The headline addition for enterprise and supply-chain watchers is support for post-quantum package signing — a forward-looking cryptographic hedge designed to keep Ubuntu's software repositories verifiable even as quantum computing advances threaten current signing schemes.</p>
<p>The announcement, published by Canonical on 15 October 2026, frames 26.10 as a release that "advances enterprise security" while layering in on-device speech-to-text, the completion of the long-running migration of coreutils to Rust, and improvements to enterprise identity integration. As background: interim Ubuntu releases carry nine months of support rather than the five years offered by Long Term Support editions — a distinction that makes 26.10 less a destination for production fleets than a proving ground for what will ship in the next LTS.</p>
<h4>Post-quantum package signing</h4>
<p>The most consequential change for anyone responsible for Linux package supply chains is the introduction of post-quantum signing for Ubuntu packages. Today's package verification rests on classical public-key algorithms that a sufficiently capable quantum computer could eventually break — a risk known in the industry as "harvest now, decrypt later," where adversaries collect signed artifacts today to compromise them retroactively tomorrow. It is worth being precise about scope: the quantum-safe upgrade applies to package and repository signatures, not to disk encryption or TLS connections.</p>
<p>By building post-quantum signing into the distribution itself rather than bolting it on later, Canonical is effectively rehearsing the cryptographic transition that every distribution and every enterprise package repository will eventually have to make. For IT teams auditing vendor roadmaps, the practical takeaway is that crypto agility — the ability to swap signing and verification algorithms without breaking the trust chain — is becoming a baseline expectation rather than a differentiator.</p>
<h4>Rust coreutils: the rollout is complete</h4>
<p>Ubuntu 26.10 also marks the completion of Canonical's multi-release effort to reimplement GNU coreutils in Rust. The company has been incrementally shipping Rust-built versions of standard command-line utilities, arguing that memory-safe implementations reduce the class of vulnerabilities that have historically plagued C-based system tools.</p>
<p>That milestone is worth pausing on. Coreutils is among the most fundamental software on any Linux system — <code>ls</code>, <code>cp</code>, <code>mv</code>, <code>cat</code> and dozens of other commands that scripts depend on daily. Rewriting them wholesale in a memory-safe language is the kind of infrastructure work that rarely generates headlines but materially shifts a distribution's long-term attack surface. It also signals that Rust has moved well past the "interesting experiment" stage in mainstream Linux development.</p>
<h4>On-device speech-to-text and Microsoft identity integration</h4>
<p>The release also previews a speech-to-text feature that runs locally on the device, a privacy-conscious alternative to cloud transcription services that send audio off-machine. Canonical is positioning this as a preview rather than a finished feature, which is consistent with the role interim releases play in the Ubuntu cycle.</p>
<p>Alongside it, Canonical says 26.10 improves its integration with Microsoft Entra ID and Microsoft identity services, adding support for multi-factor authentication and passwordless authentication scenarios. For organizations that extend Ubuntu desktops into existing Microsoft identity environments, those are the details that will matter more than the headline.</p>
<h4>Interim, but telling</h4>
<p>Nobody should deploy "Stonking Stingray" onto a server fleet expecting a decade of stability — that is not what interim releases are for. But the choices Canonical has made here — post-quantum signing, a finished memory-safe coreutils, on-device inference — read as a statement of intent about where the distribution is heading by the time these features mature into an LTS. For IT professionals tracking the open-source ecosystem, 26.10 is best understood as an early look at Ubuntu 28.04.</p>
<hr>
<p>Canonical 今日正式發布 Ubuntu 26.10，代號「Stonking Stingray」，這是其 Linux 發行版的最新過渡版本（interim build），可於 ubuntu.com/download 下載。對企業用戶及供應鏈監察者而言，最矚目的新增功能是支援 post-quantum 套件簽核——這是一項具前瞻性的加密對沖措施，旨在確保 Ubuntu 的軟件存放庫（software repositories）在量子計算發展威脅現有簽核機制之際，仍能維持可驗證性。</p>
<p>Canonical 於 2026 年 10 月 15 日發布的公告，將 26.10 定位為一個「推動企業安全」的版本，同時加入裝置端語音轉文字功能、歷時甚久的 coreutils 遷移至 Rust 的工作正式完成，以及企業身份整合方面的改進。作為背景資料：Ubuntu 過渡版本的支援期為九個月，而非 Long Term Support（LTS）版本所提供的五年——這項區別意味著 26.10 較適合作為下一個 LTS 的驗證場地，而非生產機群的部署目標。</p>
<h4>Post-quantum 套件簽核</h4>
<p>對任何負責 Linux 套件供應鏈的人士來說，影響最深遠的改動是 Ubuntu 套件引入 post-quantum 簽核。現今的套件驗證依賴傳統 public-key 演算法，而計算能力足夠的量子電腦終有一天可以破解這些演算法——業界稱此風險為「harvest now, decrypt later」（現在收集，日後解密），即攻擊者今日收集已簽核的 artifact，以待日後對其進行追溯性破壞。有必要明確界定適用範圍：quantum-safe 升級適用於套件及軟件存放庫的簽核，並不涵蓋磁碟加密或 TLS 連線。</p>
<p>Canonical 將 post-quantum 簽核直接內建於發行版本身，而非事後額外附加，實際上是預先演練了每一個發行版及每一個企業套件 repository 最終都必須進行的加密過渡。對於審視供應商路線圖的 IT 團隊而言，實際的啟示是：crypto agility——即在不破壞信任鏈的前提下更換簽核及驗證演算法的能力——正逐漸成為基本要求，而不再是差異化優勢。</p>
<h4>Rust coreutils：部署工作全面完成</h4>
<p>Ubuntu 26.10 亦標誌著 Canonical 跨越多個版本、以 Rust 重新實作 GNU coreutils 的努力正式完成。該公司一直以漸進方式推出以 Rust 編寫的標準命令列工具版本，認為記憶體安全的實作方式能夠減少長期困擾 C 語言系統工具的那類漏洞。</p>
<p>這項里程碑值得稍作停步細看。Coreutils 是任何 Linux 系統中最基本的軟件之一——包括 <code>ls</code>、<code>cp</code>、<code>mv</code>、<code>cat</code> 以及數十個腳本日常依賴的命令。以一種記憶體安全的語言全面改寫這些工具，正是這類不常見諸報端、卻實質改變發行版長期攻擊面（attack surface）的基建工作。這亦標誌著 Rust 在主流 Linux 開發中已遠遠超越「有趣的實驗」階段。</p>
<h4>裝置端語音轉文字及 Microsoft 身份整合</h4>
<p>是次發布同時預覽了一項在裝置本地運行的語音轉文字功能，相較於需要將音頻傳送至裝置外的雲端轉錄服務，這是一項更注重私隱的替代方案。Canonical 將此定位為預覽功能而非成品，這與過渡版本在 Ubuntu 開發周期中所扮演的角色一致。</p>
<p>除此之外，Canonical 表示 26.10 改進了與 Microsoft Entra ID 及 Microsoft identity services 的整合，新增對 multi-factor authentication（多重身份驗證）及 passwordless authentication（無密碼驗證）場景的支援。對於將 Ubuntu 桌面系統延伸至現有 Microsoft 身份環境的機構而言，這些細節的重要性遠大於標題功能。</p>
<h4>雖是過渡版本，卻具啟示性</h4>
<p>沒有人應該將「Stonking Stingray」部署到伺服器機群，期望獲得十年的穩定性——這並非過渡版本的用途。但 Canonical 在此作出的各項選擇——post-quantum 簽核、完成記憶體安全的 coreutils、裝置端 inference——可視為一份意向聲明，預示了當這些功能成熟並納入 LTS 之時，這個發行版將走向何方。對於追蹤 open source 生態系統的 IT 專業人士而言，26.10 最適合作為 Ubuntu 28.04 的預覽版本來理解。</p>
